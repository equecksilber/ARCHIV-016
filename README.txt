Vorschau:
Öffne index.html im Browser. Die Bilder müssen im assets-Ordner bleiben.

Online stellen:
1. Entpacke die ZIP.
2. Lade den gesamten Ordnerinhalt (index.html UND assets-Ordner) in ein GitHub-Repository hoch.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Kopiere die veröffentlichte URL in die YouTube-Beschreibung.
